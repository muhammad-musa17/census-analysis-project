Census Analysis Project
This repository contains the final outputs of a data science project focused on analyzing a mock census dataset for a mid-sized town. The project was completed as part of my university coursework for Fundamentals of Data Science (2024–2025).

Project Objective
The goal of this project was to analyze the town’s demographic, social, and economic data in order to:

Recommend what should be built on an unoccupied plot of land (e.g. housing, train station, medical center, etc.)

Advise on community service investments (e.g. education, old-age care, infrastructure)

All recommendations were made based on real data insights derived from thorough cleaning and exploratory analysis.
